    • why i made a blog

    i wanted to lie to myself and say i didnt honestly
    want to make a blog because it felt generic and unoriginal,
    but im sure almost no one will end up reading this, so i can
    be fully transparent. part of me has always felt lackluster with
    respect as to how i portray myself to others, i never feel like i
    come across just like how i would like, so i'll write here instead,
    even if no one else reads this, and word out all the thoughts i don't
    voice, all the ideas i pushed out of my mind, and all the shit that
    i was too afraid to express. i thought about getting a diary for a
    long time, but that sounds lame as fuck so id rather write it here and
    increase my commit history instead.

    im not one to yap meaninglessly, so ill leave it here for today,
    expect some more hot unemployed chud stories for a while.
